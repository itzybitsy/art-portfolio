Set up Supabase to continue

Follow these steps once, then come back here to manage your portfolio.

Step 1

Create a free Supabase project

Go to supabase.com → New project. Choose any name and region.

Step 2

Run this SQL in your Supabase SQL Editor

Go to SQL Editor → New query, paste this, and click Run:


    


    

      
Step 3

      
Create the artwork images bucket

      
Go to Storage → New bucket, name it artwork-images, and toggle Public bucket on.

    


    

      
Step 4

      
Create your admin account

      
Go to Authentication → Users → Invite user. Use your email and set a password.

    


    

      
Step 5

      
Fill in config.js

      
Go to Settings → API in your Supabase project. Copy the Project URL and anon / public key and paste them into config.js in this folder.

    


    

      
Step 6

      
Push to GitHub and Vercel will redeploy automatically

      
Once deployed, come back to /admin to log in and start adding your artwork.
